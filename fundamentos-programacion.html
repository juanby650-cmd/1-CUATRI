Sesión 1 · Introducción a la programación

De la información digital al diseño de un algoritmo.

1. Programar y pensamiento computacional

Programar es expresar instrucciones precisas para que un ordenador resuelva un problema. Antes de escribir código, identifica entradas, salida esperada y restricciones. El pensamiento computacional ayuda a descomponer el problema, abstraer lo relevante, reconocer patrones y diseñar pasos claros.

DescomposiciónSeparar una tarea compleja en subtareas.
AbstracciónIgnorar detalles irrelevantes para el objetivo.
PatronesReutilizar soluciones de problemas semejantes.
AlgoritmoOrdenar las acciones de forma finita y precisa.

2. Hardware, software y codificación

Hardware son los componentes físicos; software son instrucciones y datos que ejecuta el equipo. La electrónica representa información con dos estados, que modelamos como 0 y 1.

UnidadSignificado
bitUn dígito binario: 0 o 1.
byte8 bits; 256 patrones posibles.
kB, MB, GBPrefijos decimales: 10³, 10⁶ y 10⁹ bytes.
KiB, MiB, GiBPrefijos binarios: 2¹⁰, 2²⁰ y 2³⁰ bytes.

Sistemas binario y hexadecimal

En base 2, cada posición pesa una potencia de 2. Para pasar a decimal, suma los pesos donde hay un 1. Para pasar de decimal a binario, divide sucesivamente entre 2 y lee los restos desde el último al primero. Hexadecimal es base 16 (0–9, A–F); cada dígito equivale a cuatro bits.

Ejemplos
1011₂ = 1·8 + 0·4 + 1·2 + 1·1 = 11₁₀. Además, 25₁₀ = 11001₂ = 19₁₆.
bin(13)        # '0b1101'
int('1101', 2) # 13
hex(255)       # '0xff'
int('ff', 16)  # 255

Enteros, reales y representación del texto

En complemento a dos, n bits representan desde −2ⁿ⁻¹ hasta 2ⁿ⁻¹−1. Si el resultado excede el rango disponible puede producirse desbordamiento, según el tipo usado. Los números reales se guardan normalmente en coma flotante: muchos decimales solo pueden representarse aproximadamente, por lo que comparar floats con igualdad exacta puede ser problemático.

ASCII codifica un conjunto reducido de caracteres. Unicode asigna códigos a caracteres de muchos idiomas; UTF-8 los representa en una cantidad variable de bytes (1 a 4). Las imágenes se representan mediante píxeles y canales de color; el sonido digital, mediante muestras tomadas a intervalos regulares.

Idea importanteCodificar es representar datos con números y bits. Una imagen, texto o audio termina almacenado como patrones binarios.

3. El computador por dentro

En la arquitectura de von Neumann, instrucciones y datos se almacenan en memoria. La CPU incluye una unidad de control y una unidad aritmético-lógica; registros y caché son rápidos y pequeños, RAM es memoria de trabajo y el almacenamiento conserva datos aunque se apague el equipo. El sistema operativo administra recursos y facilita la interacción con el hardware.

Ciclo de instrucción: buscar (fetch) → decodificar (decode) → ejecutar (execute)

El contador de programa señala la próxima instrucción. Buses de datos, direcciones y control conectan componentes. El programa escrito en Python debe traducirse/ejecutarse mediante herramientas de software antes de que la CPU pueda realizar sus operaciones.

4. Algoritmos, diagramas y depuración

Un algoritmo es una secuencia finita, precisa y ordenada de pasos efectivos que resuelve un problema. Puede ser determinista (misma entrada, mismo resultado) o probabilístico (incorpora azar). Se describe con pseudocódigo o diagramas de flujo.

Algoritmo de Euclides · máximo común divisor
leer a, b
mientras b != 0:
    resto = a % b
    a = b
    b = resto
mostrar a
Con a=48 y b=18: (48,18) → (18,12) → (12,6) → (6,0), por tanto mcd=6.

En un diagrama, el óvalo suele marcar inicio/fin, el rectángulo una acción, el rombo una decisión y las flechas el orden. Para una media, suma los valores y divide por la cantidad, cuidando el caso de lista vacía.

ErrorDescripciónEjemplo
SintaxisEl código no cumple las reglas del lenguaje.Falta un paréntesis o dos puntos.
EjecuciónSe produce al ejecutar.División por cero.
LógicoCorre, pero no resuelve correctamente.Condición o fórmula equivocada.

Sesión 2 · Algoritmos, lenguajes y entorno

Qué problemas se pueden resolver, cuánto cuesta y cómo se comprueba un programa.

1. Diseñar algoritmos: estrategia voraz

Un algoritmo debe especificar qué recibe, qué produce y qué pasos conectan ambas cosas. La estrategia voraz elige en cada paso la mejor opción local disponible. Puede ser rápida y sencilla, pero no garantiza el óptimo global salvo que se justifique para el problema.

Ejemplo · dar cambio
Elegir repetidamente la moneda mayor que no supere el resto es voraz. Funciona con ciertos sistemas monetarios, pero con denominaciones arbitrarias puede usar más monedas que otra combinación.

2. Calculabilidad y problema de la parada

La calculabilidad estudia qué problemas se pueden resolver mediante algoritmos. El problema de la parada pregunta si hay un programa universal que decida para cualquier programa P y entrada x si P termina. La respuesta es no: no existe un algoritmo que resuelva todos los casos correctamente.

Consecuencia práctica. Un analizador puede detectar muchos riesgos, pero no decidir de forma perfecta todos los posibles bucles infinitos. Para programas concretos se puede razonar y probar.

3. Complejidad y eficiencia

La complejidad describe cómo crecen tiempo y memoria con el tamaño n de los datos. Big O resume el orden de crecimiento para n grande, ignorando constantes y términos menores.

OrdenEjemploIntuición
O(1)Acceso por índiceCoste constante.
O(log n)Búsqueda binariaDivide el intervalo a la mitad.
O(n)Búsqueda linealPuede revisar todos los elementos.
O(n log n)Ordenación eficienteCrece moderadamente.
O(n²)Doble recorrido / burbujaDuplicar n puede cuadruplicar trabajo.
O(2ⁿ), O(n!)Subconjuntos o permutacionesExplosión combinatoria.

La búsqueda binaria requiere datos ordenados y necesita O(log n) comparaciones; la búsqueda lineal funciona sin ordenar, pero puede necesitar O(n). Para problemas costosos (como rutas del viajante), las heurísticas buscan soluciones buenas con rapidez sin garantizar que sean las mejores.

4. Corrección e invariantes de bucle

Un programa correcto cumple la especificación para todas las entradas válidas. La corrección parcial dice que, si termina, su salida es correcta; además hay que razonar sobre la terminación. Un invariante es una propiedad que se conserva antes y después de cada vuelta del bucle.

Ejemplo · máximo de una lista
Inicializa el máximo con el primer elemento y recorre los demás. Invariante: tras procesar los primeros k valores, la variable guarda el mayor de ellos. Inicializar en 0 falla si todos los valores son negativos.

5. Lenguajes, gramáticas y traductores

Un algoritmo es una idea; un lenguaje permite escribirla con sintaxis y semántica definidas. Los lenguajes de bajo nivel se acercan al hardware; los de alto nivel simplifican la expresión de soluciones. Hay paradigmas imperativos, declarativos y orientados a objetos. La gramática define qué secuencias son válidas y el análisis sintáctico organiza expresiones en estructuras.

EnfoqueQué haceMatiz
CompiladorTraduce el programa antes de ejecutarlo.Puede optimizar; hay que compilar los cambios.
IntérpreteEjecuta mediante un programa intérprete.Facilita la interacción; no siempre es literalmente línea por línea.
Híbrido / VMTraduce a código intermedio y lo ejecuta en una máquina virtual.Python suele generar bytecode y ejecutarlo en su VM.

6. IDE y depuración

Un IDE integra editor, ejecución, depurador y herramientas de proyecto. Un breakpoint pausa el programa; avanzar paso a paso y revisar variables ayuda a encontrar cuándo se desvía el estado esperado. Los IDE en la nube facilitan acceso y colaboración, pero el código y sus dependencias siguen necesitando organización.

Sesión 3 · Primeros pasos en Python

Objetos, variables, expresiones y entrada/salida.

1. Tipos y variables

En Python cada valor es un objeto. Una variable es un nombre que referencia ese objeto; = asigna un valor y no expresa una igualdad matemática.

TipoEjemplosObservación
int3, -12Enteros.
float3.0, 9.99Usa punto decimal y representa aproximaciones.
str"hola", "3"Texto entre comillas.
boolTrue, FalseValores lógicos con mayúscula.
NoneTypeNoneAusencia de valor.

Los nombres deben describir su propósito (nota_final). Las constantes suelen escribirse en mayúsculas por convención. Una anotación como edad: int documenta el tipo esperado, pero no valida automáticamente en ejecución.

Inmutablesint, float, bool, str y tuplas: no se cambia el objeto.

2. Operadores y precedencia

3. Conversiones, entrada y salida

input() devuelve texto. Convierte antes de calcular: int() para enteros y float() para decimales. str() crea texto. Al convertir un float a int, Python trunca hacia cero. Cadenas no vacías (incluso "False") son verdaderas como booleanos; cadena vacía, cero y colecciones vacías son falsas.

nombre = input("Nombre: ")
edad = int(input("Edad: "))
print(f"Hola {nombre}; tendrás {edad + 1} el año próximo")

Una f-string inserta expresiones entre llaves. El formato {precio:.2f} muestra dos decimales. print muestra un valor; no lo devuelve para seguir calculando.

Ejemplo · IVA
precio = 80.0
cantidad = 3
subtotal = precio * cantidad
total = subtotal * 1.21
print(f"Total: {total:.2f} €")
El subtotal es 240.00 € y el total con IVA del 21 % es 290.40 €.

4. Del pseudocódigo al programa y errores

Primero decide entradas, operaciones y salida; después traduce el algoritmo, ejecuta casos de prueba y depura.

celsius = float(input("Temperatura en °C: "))
fahrenheit = celsius * 9 / 5 + 32
print(f"{celsius:.1f} °C = {fahrenheit:.1f} °F")
Leer errores: SyntaxError suele indicar sintaxis inválida; NameError, nombre desconocido; TypeError, operación incompatible; ValueError, valor no aceptado por una conversión. El traceback indica dónde se originó.

Sesión 4 · Decisiones, bucles y excepciones

Selección e iteración para controlar el flujo del programa.

1. Condiciones e if / elif / else

Las comparaciones devuelven booleanos; and exige ambas condiciones, or al menos una y not invierte. Python usa cortocircuito: deja de evaluar cuando el resultado ya está determinado. Con if se ejecuta una rama; las condiciones de elif se prueban por orden y else cubre lo restante.

if nota < 0 or nota > 10:
    print("Fuera de rango")
elif nota >= 9:
    print("Sobresaliente")
elif nota >= 7:
    print("Notable")
elif nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")
Orden de las ramasSe ejecuta solo la primera condición verdadera. Las condiciones más específicas deben ir antes de las más generales.

2. while, break y continue

while repite mientras su condición sea verdadera. Asegúrate de actualizar el estado del que depende la condición para que el bucle pueda terminar. Un centinela indica que ya no quedan datos.

suma = 0
valor = int(input("Número (-1 para terminar): "))
while valor != -1:
    suma += valor
    valor = int(input("Número (-1 para terminar): "))
print(suma)

break sale del bucle; continue pasa a la siguiente iteración.

3. for, range, contadores y acumuladores

for recorre elementos de un iterable. range(inicio, fin, paso) incluye inicio, excluye fin y usa paso 1 por defecto: range(1,6) genera 1,2,3,4,5. Un contador cuenta iteraciones/eventos; un acumulador mantiene una suma o resultado parcial.

total = 0
for numero in range(1, 6):
    total += numero
print(total)  # 15
FizzBuzz del 1 al 15
for n in range(1, 16):
    if n % 15 == 0:
        print("FizzBuzz")
    elif n % 3 == 0:
        print("Fizz")
    elif n % 5 == 0:
        print("Buzz")
    else:
        print(n)
El caso divisible por 3 y 5 va primero para que no quede absorbido por los casos individuales.

4. Excepciones y entradas válidas

Una excepción representa un problema surgido durante la ejecución. try contiene la operación arriesgada; except maneja una excepción concreta; else se ejecuta si no hubo error y finally siempre se ejecuta.

while True:
    try:
        edad = int(input("Edad: "))
        if edad < 0:
            print("Debe ser no negativa")
            continue
        break
    except ValueError:
        print("Escribe un entero válido")

Captura el error esperado (por ejemplo ValueError) en lugar de ocultar indiscriminadamente cualquier excepción. Un programa de adivinar un número combina bucle, condición, contador de intentos y validación de entrada.

Sesión 5 · Funciones y abstracción

Descomponer el programa en piezas reutilizables y comprobables.

1. Abstracción y diseño descendente

Abstraer es centrarse en lo importante para una tarea e ignorar temporalmente los detalles internos. El diseño descendente parte del objetivo general y lo divide en subtareas; cada una puede implementarse como función. Así se reduce repetición y se facilita mantener y probar el programa.

2. Definición, parámetros, argumentos y return

Una función se define con def. Los nombres en la definición son parámetros; los valores de la llamada son argumentos. return termina la función y entrega un valor; si no aparece, la función devuelve None.

def area_rectangulo(ancho, alto):
    """Devuelve el área de un rectángulo."""
    return ancho * alto

resultado = area_rectangulo(4, 3)
print(resultado)  # 12
printMuestra información; su propio retorno es None.
returnEntrega un resultado que el resto del programa puede usar.

3. Argumentos por posición, nombre y defecto

Los posicionales se emparejan por orden; los argumentos con nombre se asocian por etiqueta. Los valores por defecto hacen opcionales algunos parámetros, y se colocan después de los obligatorios.

def precio_con_iva(base, iva=0.21):
    return base * (1 + iva)

precio_con_iva(100)              # 121.0
precio_con_iva(base=100, iva=0)  # 100

4. *args, **kwargs y varios resultados

*args recoge argumentos posicionales adicionales en una tupla; **kwargs recoge argumentos nombrados en un diccionario. Una función puede devolver varios valores separados por comas: Python crea una tupla que se puede desempaquetar.

def min_y_max(datos):
    return min(datos), max(datos)

minimo, maximo = min_y_max([4, 1, 9])

5. Docstrings, tipos y contratos

El docstring va al principio de la función y explica su propósito, entradas y retorno. Las anotaciones documentan tipos previstos, pero no realizan comprobación automática por sí solas. La precondición debe cumplirse antes de llamar; la postcondición es lo que la función garantiza. assert comprueba supuestos durante desarrollo, pero no debe ser la única validación de entradas de usuario.

def cuadrado(x: float) -> float:
    """Devuelve x elevado al cuadrado."""
    return x * x

6. Ámbito y mutabilidad

Las variables creadas dentro de una función son locales. Las globales están fuera; modificar una global requiere declararla con global, aunque es preferible pasar valores como argumentos y devolver resultados. Los objetos mutables como listas pueden modificarse desde una función; los inmutables como enteros no se alteran al reasignar el parámetro local.

def agregar_cero(datos):
    datos.append(0)  # modifica la lista recibida

numeros = [1, 2]
agregar_cero(numeros)
print(numeros)  # [1, 2, 0]

7. Integradas, lambda, map y filter

Funciones integradas útiles: len, sum, sorted, min, max, type y round. Una lambda es una función breve de una expresión. map transforma elementos; filter conserva los que cumplen una condición. En Python 3 devuelven iteradores.

nums = [1, 2, 3, 4, 5]
dobles = list(map(lambda x: 2*x, nums))
pares = list(filter(lambda x: x % 2 == 0, nums))

8. Pruebas de funciones

Prueba casos normales, límites y entradas inválidas. assert falla si la condición no es verdadera.

def es_par(n):
    return n % 2 == 0

assert es_par(4) is True
assert es_par(5) is False
assert es_par(0) is True
Buenas prácticas: una responsabilidad clara por función; nombres descriptivos; entradas/salidas explícitas; pocos efectos secundarios; docstrings útiles; pruebas representativas.
